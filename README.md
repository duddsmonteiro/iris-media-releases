# Iris Media

Instaladores do **Iris Media**, player de vídeo para Windows.

- Baixe o instalador mais recente em [Releases](https://github.com/duddsmonteiro/iris-media-releases/releases/latest).
- Depois de instalado, o Iris Media se atualiza sozinho a partir daqui.

O código-fonte fica em um repositório privado.
